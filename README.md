# dovshanit
הקוד הזה הוא לא כל הקוד של דובשנית אלא רק טעימה ממנו על מנת לראות את הלוגיקה הבסיסית שלה כדי שיהיה בטוח לשימוש בקרב משתמשים 
נוצר עם ספריות phaser + electron 

הערות וטריקים במשחק הזה:
1: לחיצה על דובשנית ואז על shift + p תיפתח את התפריט בעמצה המסך וגם לחיצה ימנית על דובשנית תעשה זהות במקום שבו לחצתם
2: לחיצה שמאלית + גרירה מזיזה את דובשנית גבי כל המסך
